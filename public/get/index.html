ProjectMusic

Your music, on your own server.

ProjectMusic is free and open source. Download it, start the small server on your computer or Android phone, and this page becomes a full music app: YouTube Music catalogue, synced lyrics, share cards and more.

Windows · Mac · Linux · Android (Termux) — about 1 MB

Set it up — pick your device

  1. Install Python. Get it from python.org/downloads. In the installer, tick “Add python.exe to PATH”, then click Install Now.
  2. Download and unzip ProjectMusic with the button above. Right-click the zip → Extract All.
  3. Start the server. Open the ProjectMusic\server folder and double-click start.bat. The first start takes about a minute. Keep that window open.
  4. Open the app. Come back to this page (it turns green) and press Open ProjectMusic, or go to http://localhost:8080.

Windows may show “Windows protected your PC” the first time: click More info → Run anyway. The script only sets up Python and starts the server.

  1. Install Python. Get the macOS installer from python.org/downloads and run it. At the end, double-click Install Certificates.command in the Python folder that opens.
  2. Download ProjectMusic with the button above and double-click the zip in Downloads to unpack it.
  3. Start the server. Open Terminal (⌘ Space, type Terminal) and run: 
    cd ~/Downloads/ProjectMusic && sh server/start.sh
    The first start takes about a minute. Keep the Terminal window open.
  4. Open the app. Come back to this page and press Open ProjectMusic, or go to http://localhost:8080.

Next time, only step 3 is needed. Stop the server with Control + C in Terminal.

  1. Make sure Python 3.10+ is installed. On Ubuntu/Debian: 
    sudo apt install python3 python3-venv python3-pip
    (Fedora: sudo dnf install python3 python3-pip · Arch: sudo pacman -S python python-pip)
  2. Download and unzip ProjectMusic with the button above, or clone it: 
    git clone https://github.com/MahendraDharma/ProjectMusic
  3. Install it to your app menu (no sudo). Add --autostart to start the server at every login: 
    sh ProjectMusic/server/install-linux.sh --autostart
  4. Open ProjectMusic from your app menu. The server starts in the background and the app opens in your browser.

Remove it again with sh ProjectMusic/server/install-linux.sh --uninstall.

  3. Open the app in Chrome on the same phone: come back to this page and press Open ProjectMusic, or go to http://localhost:8080.
  4. Keep it running with the screen off: pull down the Termux notification → Acquire wakelock.

An old Android phone on a charger makes a great always-on music server for the whole house.

iPhone and iPad can’t run the server themselves, but they can use one running on your computer or Android phone.

  1. Start the server on a computer or Android phone (see the other tabs).
  2. Same Wi-Fi: the server window shows an address like http://192.168.1.5:8080. Open it in Safari.
  3. Away from home: install Tailscale on both devices and sign in with the same account, then open http://<computer-name>:8080.
  4. Make it an app: Share → Add to Home Screen.

Using it every day

Open it from this website

While the server runs, the ProjectMusic site connects to it automatically on the same device. Use Chrome, Edge or Firefox and choose Allow if asked about the local network. In Safari, use http://localhost:8080.

Install it like an app

Chrome/Edge on a computer: Install icon in the address bar. Android Chrome: ⋮ → Add to Home screen. iPhone Safari: Share → Add to Home Screen.

Without the server

The site still works with indie music from Audius, your local files and your liked songs — no setup needed.

Updating

Download the zip again (or git pull). The start scripts also update the music library tools every time they run.

Troubleshooting

Songs are listed but won’t play

Stop the server and start it again: the start script updates yt-dlp, which usually fixes it. Make sure you’re on home Wi-Fi or mobile data, not a VPN.

“Sign in to confirm you’re not a bot”

YouTube blocks servers in data centres and some VPNs. Run the server on a normal home connection.

This page says the server isn’t running, but it is

Safari blocks secure sites from talking to localhost: open http://localhost:8080 directly, or use Chrome/Edge/Firefox and allow local network access. If you changed the port, set the address in the app under Settings → Server address.

Port 8080 is already used

Start with another port: sh server/start.sh --port 9090, then open http://localhost:9090.

Pemakaian sehari-hari

Buka dari situs ini

Selama server menyala, situs ProjectMusic otomatis tersambung ke server di perangkat yang sama. Pakai Chrome, Edge, atau Firefox, dan pilih Izinkan bila ditanya soal jaringan lokal. Di Safari, buka http://localhost:8080.

Pasang seperti aplikasi

Chrome/Edge di komputer: ikon Install di bilah alamat. Chrome Android: ⋮ → Tambahkan ke layar utama. Safari iPhone: Share → Add to Home Screen.

Tanpa server

Situs ini tetap jalan dengan musik indie dari Audius, file lokal, dan lagu favoritmu — tanpa perlu pemasangan.

Memperbarui

Unduh lagi file zip (atau git pull). Skrip start juga otomatis memperbarui alat pengambil lagu setiap dijalankan.

Kalau ada masalah

Daftar lagu muncul tapi tidak bisa diputar

Matikan server lalu nyalakan lagi: skrip start memperbarui yt-dlp, yang biasanya memperbaikinya. Pastikan memakai Wi-Fi rumah atau data seluler, bukan VPN.

Muncul “Sign in to confirm you’re not a bot”

YouTube memblokir server di pusat data dan sebagian VPN. Jalankan server di koneksi rumah biasa.

Halaman ini bilang server mati, padahal menyala

Safari memblokir situs aman yang menghubungi localhost: buka http://localhost:8080 langsung, atau pakai Chrome/Edge/Firefox dan izinkan akses jaringan lokal. Kalau port diganti, atur alamatnya di aplikasi: Settings → Server address.

Port 8080 sudah dipakai

Nyalakan dengan port lain: sh server/start.sh --port 9090, lalu buka http://localhost:9090.
